# FinalFighters

Проект на Unity **6000.6.6f1** с новым Input System.

Открывайте папку проекта через Unity Hub. Unity создаёт локальные кэши и устанавливает зависимости из `Packages/manifest.json`.

## Управление

- A/D или стрелки влево/вправо — движение.
- Space — прыжок.
- Left Shift — рывок.
- X — удар.
- V — бросок оружия.

В репозитории хранятся `Assets` вместе с `.meta`, `Packages` и `ProjectSettings`. Кэши Unity, настройки пользователя и локальные сборки исключены через `.gitignore`.
